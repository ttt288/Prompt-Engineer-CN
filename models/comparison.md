# 中国模型 Prompt 适配对比

这个表用于快速判断同一个中文 Prompt 在不同模型上应该怎样调整。具体表现会随模型版本变化，建议用 `tests/` 中的样例持续评测。

| 模型 | 更适合的任务 | 常见问题 | Prompt 建议 |
|------|--------------|----------|-------------|
| DeepSeek | 代码、推理、问题拆解、批量评测 | 有时解释较多，结构化输出可能带前言 | 明确“只输出 JSON/表格”，复杂任务要求先内部分析再输出结论 |
| Qwen / 通义千问 | 中文通用任务、工具调用、企业问答、多语言 | 平台风格可能偏平，营销文案容易泛化 | 给真实中文示例，写清平台、受众、风格、禁忌和 CTA |
| GLM / 智谱 | 政企知识库、中文文档总结、正式报告 | 严肃场景下可能输出偏模板化 | 要求“结论/依据/不确定点”，表格列名固定，资料不足不猜测 |
| Kimi | 长文档、报告分析、会议纪要、资料整合 | 长文摘要可能遗漏细节或把资料混合 | 每个片段标来源，要求保留关键数字、责任人、时间和冲突点 |
| 豆包 | 中文创作、短视频脚本、小红书/抖音风格 | 可能表达偏热闹，营销感偏强 | 明确“真实分享、不硬广、不夸张承诺”，给平台语气样例 |
| MiniMax | 角色对话、多轮陪伴、内容生成 | 角色感强时容易边界漂移 | 写清角色边界、拒答规则、长期记忆和每轮任务目标 |
| 百度文心 | 中文知识问答、办公文档、电商营销 | 结构化输出需更强约束，广告表述需控风险 | 使用 schema、正反例，禁止绝对化和无法证明的功效描述 |

## 推荐评测方式

```text
同一 Prompt + 同一测试集 + 固定采样参数
-> 分别调用 DeepSeek / Qwen / GLM / Kimi / 豆包 / MiniMax / 文心
-> 记录格式合规、任务完成、中文自然度、安全性和稳定性
```

## 示例：同一任务的模型提示差异

任务：根据“至今没发现有钱的弊端”生成公众号标题。

### 通用 Prompt

```text
请围绕“至今没发现有钱的弊端”生成 10 个公众号标题。
要求有传播感，但不要低俗、标题党或制造财富焦虑。
```

### 面向创作型模型的增强

```text
请生成 10 个公众号标题，分为情绪共鸣型、观点讨论型、反差幽默型、理性分析型。
标题要有网感，但不要拜金、低俗、标题党。
每个标题后说明文章角度。
```

### 面向结构化稳定性的增强

```text
只输出 Markdown 表格：
| 类型 | 标题 | 文章角度 | 风险提示 |

主题：至今没发现有钱的弊端
规则：
- 不制造财富焦虑。
- 不使用绝对化表达。
- 不虚构数据或名人观点。
```
