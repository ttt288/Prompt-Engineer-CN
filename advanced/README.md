# Advanced Prompt Engineering

这个目录保留提示工程的高级能力模块。`SKILL.md` 负责项目入口和中文本地化方法，`advanced/` 负责系统化工程能力。

- [Multimodal Prompting](multimodal.md)
- [Agent Patterns](agent-patterns.md)
- [Safety](safety.md)

## 设计原则

- 中文场景优先，但保留通用提示工程方法。
- 每个模块都包含：适用场景、Prompt 模板、中文注意事项、常见失败。
- 不把所有内容塞进一个超长文档，方便维护和按需引用。
