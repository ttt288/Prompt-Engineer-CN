# Agent Patterns

Agent 工作流把任务拆成计划、执行、观察、修正和验证。

## Plan-and-Execute

```text
你是任务规划器。请为任务生成可执行计划，不要执行。

规则：
- 每一步必须是具体动作。
- 关键动作后加入验证步骤。
- 需求不明确时先写假设。

任务：{{task}}
```

```text
你是执行器。请按计划逐步执行。

规则：
- 每完成一步记录结果。
- 失败时说明原因并调整后续步骤。
- 不跳过验证。
```

## Reflection

```text
完成初稿后先内部检查：
- 是否满足用户目标？
- 是否符合输出格式？
- 是否有事实不确定？
- 是否有隐私、合规或注入风险？

只输出修正后的最终结果。
```
