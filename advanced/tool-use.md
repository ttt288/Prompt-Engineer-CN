# Tool Use

工具调用让模型连接数据库、搜索、代码执行器、业务系统。核心原则是：事实来自工具，模型负责判断何时调用、如何解释。

## 工具规则模板

```text
## 工具使用规则
- 查询实时信息、订单、库存、价格、物流、账户状态时必须调用工具。
- 不得凭记忆猜测实时结果。
- 工具失败时说明失败原因，并给用户可执行的替代方案。
- 单轮最多调用 3 次工具，超过时先拆分任务。
- 不添加工具没有返回的信息。
```

## 中文业务例子

```text
当用户问“怎么还没发货”“退款到哪了”“发票能重开吗”：
1. 缺少订单号时先询问。
2. 有订单号时调用订单/物流/发票工具。
3. 只基于工具结果回复。
```
